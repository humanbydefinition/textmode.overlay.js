# Contributing to `textmode.overlay.js`

Thank you for helping improve `textmode.overlay.js`.

Start with the shared [code contribution guide](https://code.textmode.art/docs/contributing/code) for repository
routing, setup, workflow, documentation, testing, asset, and review expectations.

## Quick start

```bash
npm ci
npm run check
```

Create a focused branch from `dev` and open the pull request against `dev`. Discuss features, public API changes,
DOM overlay behavior or geometry synchronization, packaging, browser support, or bundled assets in an issue before
implementation.

Add or update tests, API documentation, and examples when behavior changes. Test overlay rendering in a real browser
and include screenshots or recordings for visual changes.

Read the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities privately by following
[SECURITY.md](SECURITY.md), not through a public issue.

Need help? [Open an issue](https://github.com/humanbydefinition/textmode.overlay.js/issues), read the
[API reference](https://code.textmode.art/api/textmode.overlay.js/).
